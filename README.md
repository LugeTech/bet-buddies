## BetBuddies

BetBuddies is a product concept for a social betting and challenge app where friends use virtual currency for friendly predictions and personal challenges. It focuses on playful competition without describing any current feature as complete.

- Social betting rooms and friend-created challenges
- Virtual currency for wagers, rewards, and balances
- Profiles, achievements, and leaderboards
- Chat, sharing, and friend interaction
- Engagement ideas such as daily challenges, trivia, and seasonal events
